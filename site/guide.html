Refaire le projet pas à pas

D'un PC Windows sans aucun outil jusqu'à l'écran qui affiche votre quota. Toutes les commandes se tapent dans PowerShell, depuis le dossier du projet.

Durée : 30 à 45 minWindows 10 / 11Aucun droit administrateur

01Les étapes

Installer arduino-cli

L'outil en ligne de commande d'Arduino : un seul exécutable, installé dans le dossier utilisateur.

PowerShell
$dir = "$env:LOCALAPPDATA\arduino-cli"
New-Item -ItemType Directory -Force $dir | Out-Null
Invoke-WebRequest https://downloads.arduino.cc/arduino-cli/arduino-cli_latest_Windows_64bit.zip -OutFile "$dir\cli.zip"
Expand-Archive "$dir\cli.zip" $dir -Force
Remove-Item "$dir\cli.zip"
& "$dir\arduino-cli.exe" version
Attendu : arduino-cli Version: 1.x.x

Installer le support ESP32 et les bibliothèques

On déclare le dépôt d'Espressif, puis on installe le « core » ESP32 (environ 1 Go, compter quelques minutes) et les trois bibliothèques Adafruit.

PowerShell
$A = "$env:LOCALAPPDATA\arduino-cli\arduino-cli.exe"
& $A config init
& $A config add board_manager.additional_urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
& $A core update-index
& $A core install esp32:esp32
& $A lib install "Adafruit ST7735 and ST7789 Library" "Adafruit NeoPixel"
La bibliothèque Adafruit GFX est installée automatiquement, comme dépendance du pilote ST7789. Version utilisée pour ce projet : esp32:esp32 3.3.12.

Brancher la carte et trouver son port

PowerShell
Get-PnpDevice -PresentOnly | Where-Object InstanceId -like 'USB\VID_303A*' | Select-Object FriendlyName
Attendu : Périphérique série USB (COM3) et USB JTAG/serial debug unit. Notez le numéro du port COM. Les exemples suivants utilisent COM3.
Rien n'apparaît ?

Essayez un autre câble. Sinon, forcez le mode téléchargement : maintenir BOOT, appuyer sur RESET, relâcher BOOT.

Premier test : Hello World

Avant le vrai projet, on vérifie que la chaîne complète fonctionne : compilation, téléversement et affichage.

PowerShell, depuis le dossier du projet
$F = "esp32:esp32:esp32c6:CDCOnBoot=cdc"
& $A compile --fqbn $F firmware\hello_world
& $A upload  --fqbn $F -p COM3 firmware\hello_world
Résultat attendu

« Hello World » en blanc, « MiniDisplay C6 » en jaune, un cadre cyan sur les quatre bords, et la LED qui passe par toutes les couleurs. Si le cadre est coupé d'un côté, le décalage de l'écran est faux.

Téléverser le firmware du projet

PowerShell
& $A compile --fqbn $F firmware\claude_usage
& $A upload  --fqbn $F -p COM3 firmware\claude_usage
L'écran affiche « Claude usage », des jauges vides et, en bas, « En attente du PC (lancez le pont USB)... ». C'est normal : la carte attend ses données.

Tester le pont une fois

Le paramètre -Once fait un seul relevé, un seul envoi, et affiche tout dans la console :

PowerShell
powershell -ExecutionPolicy Bypass -File bridge\MiniDisplayBridge.ps1 -Once
Sortie attendue
2026-10-17 10:31:08  MiniDisplay Bridge demarre
2026-10-17 10:31:08  Quota : 5 h 27 %, semaine 29 %
2026-10-17 10:31:09  Carte connectee sur COM3
2026-10-17 10:31:09  -> Q;1792233069;27;1792248600;29;1792692000;0;1792233068;
L'écran se remplit aussitôt. Il repassera en « PC deconnecte » au bout de 2 minutes, puisque le test s'arrête après un envoi.

Lancer le pont pour de bon

Double-cliquez sur bridge\Start-MiniDisplayBridge.vbs. Aucune fenêtre ne s'ouvre : le pont tourne en arrière-plan. Pour vérifier qu'il travaille, ouvrez bridge\bridge.log : une ligne « -> Q;… » s'ajoute toutes les 30 secondes.

02Démarrage automatique avec Windows

Pour que le pont démarre à chaque ouverture de session :

  1. Appuyez sur Win + R, tapez shell:startup puis Entrée. Le dossier Démarrage s'ouvre.
  2. Faites un clic droit sur Start-MiniDisplayBridge.vbs, puis Afficher d'autres options → Créer un raccourci.
  3. Déplacez ce raccourci dans le dossier Démarrage.

03Modifier le firmware

Le cycle de travail, à chaque modification de claude_usage.ino :

PowerShell
powershell -ExecutionPolicy Bypass -File bridge\Stop-MiniDisplayBridge.ps1   # 1. libérer le port
& $A compile --fqbn $F firmware\claude_usage                                 # 2. compiler
& $A upload  --fqbn $F -p COM3 firmware\claude_usage                         # 3. téléverser
Start-Process bridge\Start-MiniDisplayBridge.vbs                               # 4. relancer le pont
Oublier l'étape 1 donne une erreur de téléversement « port busy » ou « access denied » : le pont occupe le port.

04En cas de souci

  • Lire le pied de l'écran : il indique presque toujours la cause. Voir Quand quelque chose casse.
  • Lire bridge\bridge.log. Voir le dépannage du pont.
  • Problème de carte ou de port : voir l'USB natif.
